# 开发说明

## 运行环境

插件面向 Unraid 7.2，已在 7.2.2 / PHP 8.3.26 验证。运行时使用系统自带的 PHP SQLite3，不需要额外数据库服务。

## 构建安装包

开发机需要 Python 3，在项目根目录运行：

```sh
python3 scripts/build.py
```

输出为 `dist/disknap.plg`，源码和本地图表资源内嵌在安装包中。安装步骤见 [README](../README.md#安装)。当前版本采用手动安装和更新，没有在线更新地址。

## 测试

测试环境需要 PHP SQLite3、Python 3、Node.js 和 Bash，在项目根目录运行：

```sh
php tests/stats.php
php tests/database.php
php tests/analysis.php
php tests/alerts.php
php tests/collect.php
python3 -m unittest discover -s tests -p 'test_*.py'
node --check source/analysis.js
find source -name '*.php' -exec php -l {} \;
```

测试覆盖状态转换、采样中断、重启、SQLite 事务与版本升级、历史聚合、通知冷却及失败重试。实机测试范围和未验证项目见 [实机验证](实机验证.md)。

## 配置、数据与日志

- 配置：`/boot/config/plugins/disknap/config.json`，仅保存设置时写入。
- 统计：默认 `/mnt/cache/appdata/disknap/stats.sqlite`，结构见 [SQLite 数据结构](SQLite数据结构.md)。
- 错误：Unraid 系统日志 `/var/log/syslog`，标记 `disknap`，不逐次记录成功采样。
- cron 每分钟运行，按配置的间隔采样，并重试待发通知。
