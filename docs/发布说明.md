# DiskNap 2026.11.10f（公开测试版）

首个公开测试版本，已在 Unraid 7.2.2 上使用和验证。

- 主界面显示近 24 小时休眠率和唤醒次数。
- 详情页提供休眠率、唤醒次数趋势与休眠时长分布。
- 支持单盘筛选、最长 1 年预设范围及自定义日期。
- 短休眠后唤醒时发送 Unraid 通知，支持阈值、冷却和失败重试。
- SQLite 保存统计，数据位置和采样间隔可设置。

## 安装

下载附件 `disknap.plg`，或在 Unraid「插件 → 安装插件」粘贴：

```text
https://github.com/caidesen/unraid-disknap/releases/download/2026.11.10f/disknap.plg
```

需要 Unraid 7.2 或以上。默认数据库为 `/mnt/cache/appdata/disknap/stats.sqlite`，SSD 池名称不同的用户安装后须修改数据位置。`SHA256SUMS` 提供安装包 SHA-256 校验和。

## 已知限制

个人自用项目，其他版本和硬件尚未验证。默认 5 分钟采样可能漏记短暂休眠或唤醒，通知不能定位唤醒程序。历史数据暂不自动清理。安装和更新保留配置及历史。
