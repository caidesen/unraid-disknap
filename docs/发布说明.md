# DiskNap 2026.11.11（公开测试版）

本版增加首次安装自动选择 SSD 存储池，已在 Unraid 7.2.2 上验证。

- 主界面显示近 24 小时休眠率和唤醒次数。
- 详情页提供休眠率、唤醒次数趋势与休眠时长分布。
- 支持单盘筛选、最长 1 年预设范围及自定义日期。
- 短休眠后唤醒时发送 Unraid 通知，支持阈值、冷却和失败重试。
- SQLite 保存统计，数据位置和采样间隔可设置。

## 安装

下载附件 `disknap.plg`，或在 Unraid「插件 → 安装插件」粘贴：

```text
https://github.com/caidesen/unraid-disknap/releases/download/2026.11.11/disknap.plg
```

需要 Unraid 7.2 或以上。首次安装优先选择 appdata 所在的 SSD 池，其次选择唯一 SSD 池；无法确定时请到设置中填写数据位置。已有路径和历史继续保留。`SHA256SUMS` 提供安装包 SHA-256 校验和。

## 已知限制

个人自用项目，其他版本和硬件尚未验证。默认 5 分钟采样可能漏记短暂休眠或唤醒，通知不能定位唤醒程序。历史数据暂不自动清理。安装和更新保留配置及历史。
