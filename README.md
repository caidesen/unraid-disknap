# DiskNap

Unraid 硬盘休眠统计插件，用来查看硬盘休眠率、唤醒次数，以及休眠后很快又被唤醒的情况。

**个人自用项目，现分享给有相同需求的人。当前为公开测试阶段，仅在 Unraid 7.2.2 上验证，其他版本和硬件环境尚未验证。**

## 功能

- 主界面显示最近 24 小时的休眠率和唤醒次数。
- 独立详情页提供休眠率趋势、唤醒次数趋势、休眠时长分布和单盘筛选。
- 支持查看 24 小时、7 天、30 天、90 天、1 年及自定义时间范围。
- 硬盘短时间休眠后被唤醒时，通过 Unraid 系统通知提醒。
- 默认每 5 分钟统计一次，可调整为 1–60 分钟。

仅读取 Unraid 的磁盘状态，不主动唤醒硬盘，不执行 SMART 检测或硬盘启停命令。统计对象为已分配的机械硬盘，不包含 SSD 和未分配设备。

## 安装

先按 [构建说明](docs/开发说明.md#构建安装包) 生成 `disknap.plg`，复制到 Unraid 的 `/boot/config/plugins/disknap.plg`，然后在 Unraid 终端执行：

```sh
plugin install /boot/config/plugins/disknap.plg
```

目前采用手动安装，尚未上架 Community Applications，也不支持在线自动更新。

## 使用

- **主界面 → DiskNap**：查看最近 24 小时的数据。
- **查看详情**：查看图表、选择时间范围和硬盘。
- **设置 → 用户程序 → DiskNap**：修改统计间隔、数据位置和通知选项。

通知默认开启：休眠不超过 **10 分钟**就被唤醒时提醒，同一硬盘 **60 分钟**内不重复提醒。这两个时间均可修改，也可关闭通知。通知渠道沿用 Unraid 系统配置，发送失败会自动重试。

## 数据保存

统计数据默认保存在：

```text
/mnt/cache/appdata/disknap/stats.sqlite
```

可在设置中修改位置，保存时自动迁移数据。请选择已挂载的 **SSD 存储池直接路径**，不要使用 `/mnt/user`，并避免被 Mover 移到机械盘。目标文件须不存在。

统计数据不写入启动盘。卸载插件会保留配置和统计数据。

## 使用限制

- 统计从安装后开始，不会生成过去的数据。
- 时长和次数根据定时采样估算，两次采样之间的短暂休眠或唤醒可能漏记。需要更细的记录时，可将间隔设为 1 分钟。
- 异常通知表示休眠时间较短，不能判断是哪个程序唤醒了硬盘。
- 历史数据暂不自动清理；数据量较大时，请缩小查询范围或选择单块硬盘。
